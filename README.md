# Система обліку студентів та їх успішності

Курсовий проєкт з дисципліни "Об'єктно-орієнтоване програмування" (ООП).

## 🛠 Технологічний стек
- **Мова:** Python 3.x
- **GUI:** PyQt5
- **База даних:** SQLite3

## 📋 Основні можливості
- Повний CRUD для студентів (додавання, редагування, видалення).
- Автоматична генерація унікального номера студентського квитка (`KB-XXXXXX`).
- Управління навчальними групами та дисциплінами.
- Виставлення оцінок за 12-бальною шкалою.
- Підрахунок середнього бала студента з округленням до десятих.
- Пошук, фільтрація за групами та сортування (за прізвищем, найвищим та найнижчим балом).
- Сучасний графічний інтерфейс на QSS-стилях.
